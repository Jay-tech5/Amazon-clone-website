# 🛒 Amazon Clone Website

A responsive **Amazon Clone Website** built using HTML and CSS. This project is created for learning and practicing frontend web development concepts such as layouts, Flexbox, navigation bars, product sections, and responsive design.

## 🚀 Features

* 🏠 Amazon-style homepage
* 🔍 Search bar UI
* 📦 Product sections
* 🛍️ Shopping cart UI
* 📍 Location and delivery section
* 👤 Account & Sign-in section
* 📱 Responsive layout
* 🎨 Amazon-inspired design
* 🧭 Navigation menu
* 🖼️ Product images and banners

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **Flexbox**
* **Responsive Web Design**

## 💻 How to Run

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder:

```bash
cd Amazon-Clone
```

3. Open `index.html` in your browser.

Or use **VS Code Live Server** to run the project.
